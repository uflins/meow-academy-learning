# 題目格式與出題器介面

遊戲裡每一題都是一個 JavaScript 物件（題庫 JSON 檔裡也是同樣的格式）。題目有兩種來源：

- **出題器**（`js/gen/*.js`）：數學等可以隨機產生的題目，每次玩都不一樣。
- **題庫**（`data/questions/**/*.json`）：國語、自然、社會、注音等固定題目，由家長校對。

## 1. 題目物件

```js
{
  id: "math5-u2-2-2-x1",        // 題庫題目要固定、唯一；出題器題目可用 makeId() 產生
  grade: 5,                      // 1 或 5
  subject: "math",               // chinese | math | science | social
  unit: "2",                     // 單元（字串）
  section: "2-2",                // 節（字串）；一年級國語用課次，例如 "3"、"r1"（複習一）
  type: "choice",                // 見第 2 節
  prompt: "下面哪一個是 18 的因數？",   // 畫面上的題目文字，可含 \n
  speak: "下面哪一個是十八的因數？",    // 選填；朗讀用的文字。一年級每題都要有
  visual: null,                  // 選填；題目附圖，見第 3 節
  options: ["4", "5", "6", "7"], // choice / multi 用
  answer: "6",                   // 見第 2 節
  explanation: "18 ÷ 6 = 3，可以整除，所以 6 是 18 的因數。",
  explainSpeak: null,            // 選填；說明的朗讀文字（一年級建議提供）
  difficulty: 1,                 // 1–3
  tags: ["factor"]               // 選填；觀念標籤，家長區統計「最常錯的觀念」用
}
```

## 2. 題型（type）

| type | 畫面 | 必填欄位 | answer 的格式 |
|---|---|---|---|
| `choice` | 2–4 個選項按鈕，點一個 | `options` | 正確選項的 `label` 字串 |
| `multi` | 選項可以複選，按「確定」送出 | `options` | 正確選項 label 的陣列，例如 `["1","2","3","6"]` |
| `truefalse` | ⭕ / ❌ 兩個按鈕 | — | `true` 或 `false` |
| `input` | 數字鍵盤輸入 | `keypad` | 字串，例如 `"36"`、`"2/3"`、`"0.25"`；可另給 `accept: [...]` 列出其他可接受的寫法 |
| `order` | 把卡片依序點一次排好 | `items`（正確順序） | 不用填，`items` 本身就是答案 |

`keypad`：`"digits"`（0–9）、`"fraction"`（0–9 加 `/`）、`"decimal"`（0–9 加 `.`）、`"degree"`（0–9，答案單位為度，畫面顯示 °）。一年級固定用 `"digits"`，畫面會換成 0–10 的大按鈕。

`options` 的每一項可以是字串，或物件：

```js
{ label: "ㄇㄠ", image: "🐱", speak: "貓" }
```

- `label`：按鈕上的字，也是比對答案用的值，同一題不可重複。
- `image`：選填，按鈕上的圖（目前用 emoji）。只用 iPad 內建就有、意思一看就懂的 emoji。
- `svg`：選填，按鈕上的小圖（SVG 字串，規則同第 3 節），例如「哪一張折線圖畫對了？」的選項。`label` 這時可用「甲」「乙」「丙」。
- `speak`：選填，一年級點選項時會先念出來。

## 2.1 一年級題目的額外規則

- 每題都要有 `speak`，孩子聽得懂題目，不需要識字。
- 選項 2–3 個，盡量有 `image`。
- iPad 朗讀單一注音符號（例如只念「ㄅ」）常常念不準，所以 `speak` 和選項的 `speak` 要寫成**詞語**（例如「貓」），不要只寫注音符號。需要單一符號發音的題目，加上 `needsAudio: "ㄅ"`，等之後有錄音檔再開放。

## 3. 題目附圖（visual）

| 寫法 | 用途 |
|---|---|
| `{ svg: "<svg viewBox=...>...</svg>" }` | 長條圖、折線圖、多邊形、對稱圖形等。出題器自己畫好 SVG 字串。寬高用 `viewBox`，不要寫死 `width`/`height`；顏色用實色，不要依賴外部 CSS |
| `{ emojiGroups: [{ emoji: "🐟", count: 3, label: "小白" }, { emoji: "🐟", count: 5, label: "小黑" }] }` | 一年級數數、比多少、分與合。`label` 選填 |
| `{ splitDiagram: { total: 9, parts: [4, null] } }` | 分合圖。`null` 的格子顯示「?」；`total` 也可以是 `null` |

## 4. 出題器模組介面

每個出題器檔案（例如 `js/gen/math5.js`）匯出：

```js
export const subject = "math";
export const grade = 5;
export const units = [
  {
    unit: "1",
    title: "折線圖",
    sections: [
      { section: "1-1", title: "認識複雜長條圖和折線圖", make(rng, difficulty) { /* 回傳一題 */ } },
      { section: "1-2", title: "繪製折線圖", make(rng, difficulty) { ... } },
    ],
  },
  ...
];
```

- `make(rng, difficulty)` 每呼叫一次回傳一題新題目，`difficulty` 是 1–3。同一節裡有好幾種題型時，由 `make` 自己隨機挑一種。
- 只用 `js/gen/util.js` 的工具和標準 JavaScript，不依賴瀏覽器 API（要能在 Node 跑測試）。
- 數字範圍、題型依 `範圍整理/` 裡的出題素材；題目要自己出，不要照抄自修或課本的題目。
- 說明（explanation）要短，一兩句話講出關鍵步驟，五年級孩子看得懂。

## 5. 題庫 JSON 檔

路徑：`data/questions/g{年級}/{科目}/{單元或課}.json`，內容是題目物件的陣列。例如 `data/questions/g1/chinese/lesson-3.json`。
